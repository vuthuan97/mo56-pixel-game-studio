# PROMPT THIẾT KẾ GIAO DIỆN STUDIO

Thiết kế UI editor chuyên nghiệp:
- Toolbar trên.
- Asset/Entity Browser trái.
- Main Preview giữa.
- Inspector phải.
- Timeline/Event panel dưới.
- Workspace/tab: Project, Character, Rig, Equipment, Animation, Behavior, Validation, Export.
- Resizable panels, shortcuts, dirty state, Undo/Redo, status bar.

Không để domain logic trong UI. Không dùng một trang dài toàn ComboBox.
