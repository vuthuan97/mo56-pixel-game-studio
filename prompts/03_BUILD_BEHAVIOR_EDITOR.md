# PROMPT XÂY POSE / ANIMATION / BEHAVIOR

Đọc `docs/CHARACTER_AND_BEHAVIOR_SPEC.md` và rule/skill liên quan.

Triển khai hoàn chỉnh chuỗi Pose → Animation → Behavior.

- Pose Editor chỉnh root/body/head/tay/chân/hair/held item.
- Timeline add/delete/duplicate/reorder/copy/paste, duration, FPS, loop, onion skin, play/pause, marker.
- Behavior Library có preset theo nhóm và behavior tùy chỉnh.
- Behavior gắn held item, interaction anchor, effect/sound/gameplay marker.
- Preset chỉ là data, không hard-code vào UI.
- Save/reuse/import/export behavior template.

Chạy test/build và cập nhật task/state.
