# PROMPT TIẾP TỤC

Tiếp tục Pixel Game Studio theo code và tài liệu hiện tại.

Trước khi sửa: đọc `.agents/AGENTS.md`, `docs/CURRENT_STATE.md`, `tasks/TASK_LIST.md` và rule/skill liên quan. Audit code task hiện tại.

Sau đó chọn task chưa hoàn thành phù hợp nhất trong phase hiện tại, triển khai code thật, viết/cập nhật test, chạy build/test, fix lỗi, cập nhật TASK_LIST/CURRENT_STATE.

Giữ data-driven; không hard-code game tu tiên/top-down/32x46/role/slot. Pose → Animation → Behavior phải tách rõ. Tận dụng prototype v6 khi hữu ích nhưng migration về architecture mới.

Cuối lượt báo cáo ngắn: việc đã làm; file thay đổi; build/test; cách nghiệm thu; phần còn thiếu; task tiếp theo.
