# Pixel Sprite Studio v6

Bản v6 tích hợp cả hai hướng nâng cấp:

- **Art quality**: Art QA, Anchor Debug, Asset Library, Native readability workflow.
- **Production editor**: Timeline pose overrides, Anchor editor, Asset Library, Godot export.

## Editor mới
- Timeline: chỉnh offset body/head và state tay/chân/tóc/vũ khí theo từng frame.
- Anchor editor theo từng hướng.
- Asset Library: import/apply PNG theo equipment slot.
- Art QA: palette count, visible bounds, value range.
- Godot export: `sprite_frames.tres`, metadata và sample GDScript.

`run.bat`
