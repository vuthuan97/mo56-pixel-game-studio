# ART STYLE RULES v6
- Canvas 32x46.
- Mobile portrait, top-down / 3/4 top-down.
- Body and equipment are separate layers.
- Native 1x readability required.
- Hair/weapon/equipment silhouette prioritized over micro-detail.
- Prefer 2-3 tones per material.
- Use Grayscale, Silhouette, Part Debug, Anchor Debug and Art QA.
