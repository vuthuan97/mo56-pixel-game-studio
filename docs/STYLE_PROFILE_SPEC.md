# Hồ sơ phong cách Project

Mỗi project có Style Profile dùng cho mọi asset.

- pixel size / canvas defaults;
- view/perspective;
- palette và giới hạn màu;
- outline style/thickness;
- light direction;
- shadow/highlight levels;
- detail density;
- transparency rules;
- nearest-neighbor rule;
- character proportions;
- environment proportions;
- native-scale readability rules.

Các version sau phải dùng lại profile này cho item, prop, tree, rock, terrain, building, background, effect và UI.
